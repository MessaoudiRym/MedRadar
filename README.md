# MedRadar

**MedRadar helps Algerian patients find an out-of-stock medicine: a registered equivalent, or a nearby pharmacy that has it.**

## The problem

Medicine shortages are frequent in Algeria. Patients, especially those with chronic conditions (diabetes, hypertension, thyroid disorders, epilepsy), go from pharmacy to pharmacy or back to their doctor, even when:

- another medicine with the **same active ingredient, dose and form** is registered and available, or
- a pharmacy two kilometres away has it in stock.

## What MedRadar does

One question: *"I can't find my medicine, what now?"* Two answers:

1. **Equivalents** — medicines with the same active ingredient (INN/DCI), the same dose and the same form, taken from the official Algerian national nomenclature. Equivalents are found by fixed rules on official data, never generated by AI.
2. **Availability** — a map of nearby pharmacies that declared the medicine in stock, with an alert when it comes back.

Pharmacists update their stock in two taps.

> MedRadar never replaces a pharmacist's or doctor's advice. It shows options to discuss with them.

## Run locally

```bash
git clone https://github.com/<your-username>/MedRadar.git
cd MedRadar
pip install -r requirements.txt
python scripts/clean_nomenclature.py
python scripts/check_equivalents.py GLUCOPHAGE LEVOTHYROX
```

### API

The API reads `data/clean/medicaments.csv` once at startup, so run `scripts/clean_nomenclature.py` first.

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

- API: http://localhost:8000 (for example http://localhost:8000/medicines/search?q=glucofage)
- Interactive documentation: http://localhost:8000/docs

| Route | What it returns |
| --- | --- |
| `GET /health` | Status and number of medicines loaded |
| `GET /medicines/search?q=...&limit=10` | Medicines matching a brand name or active ingredient, typos allowed |
| `GET /medicines/{id}` | Full details of one medicine |
| `GET /medicines/{id}/equivalents` | The medicine, its equivalents and a safety notice |

Optional environment variables:

- `MEDICINES_CSV`: path to another cleaned CSV (default: `data/clean/medicaments.csv`)
- `FRONTEND_URL`: production frontend URL allowed by CORS (`http://localhost:3000` is always allowed)

Run the tests from `backend/`:

```bash
python -m pytest
```

## How equivalents are found

Two medicines are suggested as equivalents only when all three rules match:

1. **Same active ingredient.** The INN/DCI is cleaned so that different spellings of the same substance match: "CHLORHYDRATE DE METFORMINE" = "METFORMINE CHLORHYDRATE", "AMLODIPINE BESILATE EXPRIME EN AMLODIPINE" = "AMLODIPINE SOUS FORME BESYLATE", and "IRBESARTAN/AMLODIPINE" = "AMLODIPINE/IRBESARTAN".
2. **Same dose, after normalization.** "1G", "1 000 MG" and "1000MG" are the same dose; micrograms, grams and litres are converted to one unit.
3. **Same form group.** The ~680 ways the file writes forms are grouped into about thirty groups (tablet, capsule, syrup, injectable, eye drops...). Modified-release and gastro-resistant forms are always kept apart: an extended-release tablet is never suggested in place of a normal tablet.

Only medicines sold in community pharmacies and not withdrawn or non-renewed are suggested.
